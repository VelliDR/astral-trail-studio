# 🌌 Astral Trail Studio

Interactive HTML5 Canvas star trail visualizer & recording studio built with modular Vanilla JS.

## ✨ Features

- **Motion Modes:** ⭕ Matrix Circle, ✨ Free Flow, 🧘 Zen Mode (Keplerian physics & breathing loops)
- **Shapes & Colors:** ✦ Star, ♥ Heart, ◆ Diamond, • Dot with multiple color palettes
- **🌀 Chaos Mode:** Generative random physics, shapes, and neon color shifts
- **📁 Custom Background:** Upload images to draw star trails over your photos
- **🎥 WebM Recording:** Record canvas interactions live and export as `.webm` videos
- **High-DPI Support:** Crisp vector rendering on Retina/OLED screens
